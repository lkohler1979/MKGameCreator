# PRD - MKGameCreator MVP

## Objetivo
Permitir que qualquer usuário transforme um desenho em um jogo jogável em menos de 60 segundos.

## Personas
- Crianças
- Pais
- Professores

## Funcionalidades
1. Login
2. Dashboard
3. Upload de imagem
4. Remoção automática do fundo
5. Escolha do personagem
6. Template Plataforma
7. Geração automática da fase
8. Gameplay
9. Compartilhamento

## Fora do MVP
Editor de fases, multiplayer, marketplace, IA generativa de fases.

## Critérios de aceite
- Upload <10MB
- PNG transparente gerado
- Fase criada automaticamente
- Link compartilhável
